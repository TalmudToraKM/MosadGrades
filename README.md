# אפליקציית ציונים לאנדרואיד (לא מחוברת לרשת)

אפליקציה פשוטה שרצה על טלפון Android 4.1.2 (API 16), כמו Galaxy GT-S6310. היא עובדת בלי אינטרנט.
הנתונים נשמרים בטלפון, והחילופים עם המערכת נעשים בקבצי JSON.

## מה האפליקציה עושה

1. **ייבוא מהמערכת:** קוראת קובץ ייצוא JSON מהמודול "ציונים ומיומנויות" של המערכת. נקראים התלמידים, המבחנים הקיימים והציונים.
2. **הזנת ציונים:** בוחרים כיתה, בוחרים מבחן, ורושמים ציון (0-100) והערה לכל תלמיד. השמירה נעשית כשיוצאים מהשדה.
3. **ייצוא לקובץ:** כותבת את כל הציונים וההערות שנרשמו בטלפון לקובץ JSON, באותו מבנה. המערכת מייבאת את הקובץ הזה ישירות.

## הנחות שנקבעו (אפשר לשנות)

- **אין יצירת מבחנים חדשים באפליקציה.** המערכת מייבאת ציונים למבחנים קיימים בלבד, לכן האפליקציה רושמת ציונים רק למבחנים שיובאו מהמערכת.
- **החילופים בתיקייה קבועה:** `/sdcard/Mosad/`. מעתיקים לשם את קובץ הייצוא מהמערכת בכבל USB או בכרטיס זיכרון, וכך גם את הקובץ שהאפליקציה כותבת.
- **מיזוג בייבוא:** ערך בקובץ מעדכן את הערך בטלפון. ערך ריק בקובץ לא מוחק ציון שנרשם בטלפון.
- **מדדי קריאה מתקדמים לא נכללים בגרסה הזו.** הם נקראים מה-JSON אבל לא נערכים באפליקציה.
- **אין כניסה עם סיסמה.** הטלפון מכיל נתוני ציונים, לכן כדאי לנעול אותו במסך נעילה.

## בניית ה-APK

### אפשרות א': Android Studio במחשב (מומלץ)
1. מתקינים את Android Studio (חינם).
2. File ← Open ← בוחרים את התיקייה `app_android`. הסטודיו מוריד את הכלים לבד.
3. Build ← Build Bundle(s) / APK(s) ← Build APK(s).
4. ה-APK נמצא ב-`app/build/outputs/apk/debug/app-debug.apk`.

### אפשרות ב': GitHub Actions (בלי להתקין כלום במחשב)
1. מעלים את התיקייה `app_android` למאגר GitHub (פרטי או ציבורי).
2. בלשונית Actions מריצים את "Build APK" (או דוחפים שינוי).
3. מורידים את הקובץ `MosadGrades-debug-apk` מסיום הריצה. בתוכו קובץ `app-debug.apk`.

### התקנה על הטלפון
1. מעתיקים את ה-APK לטלפון.
2. בהגדרות ← אבטחה מאפשרים "מקורות לא ידועים".
3. פותחים את הקובץ ומתקינים.

## קבצים בפרויקט

- `app/src/main/java/il/mosad/grades/Db.java` - מסד הנתונים המקומי (SQLite).
- `Io.java` - ייבוא וייצוא JSON.
- `MainActivity.java` - מסך ראשי: כיתות, ייבוא, ייצוא.
- `ExamListActivity.java` - מבחני כיתה.
- `ExamActivity.java` - גיליון הציונים של מבחן.
- `app/build.gradle` - הגדרות בנייה (minSdk 16).

## מה לא נבדק עדיין

הקוד נכתב ללא קומפילציה בסביבה שבה נכתב. אחרי הבנייה הראשונה צריך לבדוק על המכשיר האמיתי: ייבוא קובץ, הזנת ציון, ייצוא, וייבוא חזרה למערכת.
